# FloatNote · 让简谱浮起来

一个纯静态、无后端、无需构建的开源多乐器简谱演奏器。把文本简谱粘贴进来，用 QWERTY 键盘在钢琴、吉他、小提琴、萨克斯、笛子之间切换，让音符变成声音，也变成 Canvas 2D 里的柔光、烟雾和粒子。

项目定位是个人自娱向的音乐交互实验，适合练习旋律、听不同乐器的音色、试玩光效和做二次开发。

---

## 特点

- **纯静态**：原生 HTML5 + CSS3 + ES Modules，没有前端框架、没有打包步骤、没有后端。
- **五种乐器**：钢琴、吉他、小提琴、中萨克斯、笛子；每种乐器有独立音域、键位、混响预设和光效。
- **本地采样音色**：WebAudioFont 音色文件放在 `vendor/`，离线可用；加载失败自动降级到内置合成音色，不中断演奏。
- **可调整的声光**：统一 ADSR、总音量、乐器音量、混响开关/湿度/长短预设；Canvas 粒子亮度、密度、主色调可调。
- **文本简谱解析**：调号、拍号、BPM、八度、半音、时值、连音线、小节线；错误带行号/列号，边界场景有提示。
- **完整播放控制**：调速、节拍器、整曲循环、A–B 循环、进度拖拽跳转。
- **智能编配建议**：按音域跨度、节奏密度、速度、五声性判断流派，推荐主奏、伴奏、混响与速度，全部可手动覆盖。
- **响应式**：桌面三栏；平板控制面板收进抽屉；移动端保留浏览、搜谱、播放，不提供触屏虚拟键盘。
- **独立页面**：`about.html` 图文介绍与许可说明；`404.html` 与主站视觉统一，适配 GitHub Pages。

## 快速开始

必须通过 HTTP 静态服务打开。ES Modules 在 `file://` 下会被浏览器拦截，双击 HTML 文件会报错。

### Windows 一键启动（推荐）

直接双击项目根目录的 **`start.bat`**：它会自动启动本地服务器并在约 2 秒后打开浏览器访问 `http://localhost:8080/`。弹出的黑色命令行窗口就是服务器，**保持打开**，用完关掉即停止服务。

> 前置条件：需要安装 Python 并带有官方启动器 `py`（`C:\Windows\py.exe`，安装 Python 时默认附带）。脚本用的是 `py -m http.server 8080`，而不是 `python`——因为 Windows 应用商店的 `python` 占位程序会静默退出，导致服务起不来。若未安装 `py`，请用下面的命令行方式。
>
> 若提示 `8080` 端口被占用，先关掉占用端口的程序，或按下面的命令行方式换一个端口（如 8090）。

### 命令行启动（跨平台）

```bash
# 任选一种
python -m http.server 8080
# 或
npx serve .
# 或使用 VS Code 的 Live Server 插件
```

然后打开：

```text
http://localhost:8080/
```

浏览器要求：Chrome、Edge、Firefox 的现代版本。需要 WebAudio API 与 Canvas 2D；首次点击/按键会唤醒 AudioContext。

## 简谱格式

### 开头声明（可选）

```text
1=C 4/4 ♩=80
```

- 调号：`1=C`、`1=G`、`1=F`，也支持 `1=Bb`、`1=C#` 这类常见调名。
- 拍号：`4/4`、`3/4`、`2/4`，也接受分母为 2、4、8、16 的拍号。
- 速度：`♩=80` 或 `BPM=80`，范围 20–300。
- 不写则默认 `1=C 4/4 ♩=80`。

### 音符

| 写法 | 含义 |
| --- | --- |
| `1 2 3 4 5 6 7` | 基础音级，默认四分音符 |
| `1.` | 低八度 1 |
| `1'` | 高八度 1 |
| `#1` | 升半音 |
| `1_` | 八分音符（下划线继续叠加可继续减半） |
| `1-` | 二分音符 |
| `-` | 单独写时，延长前一个音符一拍 |
| `1~` | 连音线；与下一个同音高音符合并时值 |
| `|` | 小节线 |
| `0` | 休止符（兼容扩展） |

空格分隔音符，换行会被忽略。完整示例：

```text
1=C 4/4 ♩=84
1 1 5 5 | 6 6 5 - | 4 4 3 3 | 2 2 1 - |
5 5 4 4 | 3 3 2 - | 5 5 4 4 | 3 3 2 - |
```

解析器还处理了这些情况：

- 空文本、纯空白：提示“请输入简谱文本”。
- 调号/拍号写错：自动降级到 C 调 / 4/4，并在状态区给出提示。
- 无法识别的音符：显示行号、列号、原因，保留上一份可播放的乐谱，不崩溃。
- 小节拍数与拍号不一致：给出警告但仍可播放。
- 超出当前乐器音域：自动移八度，乐谱预览中会标记。

### 暂不支持

装饰音、滑音、强弱记号、反复记号、房子记号、图片/PDF、图片 OCR、五线谱、多声部/和弦同时发声、歌词对齐。降号写法也暂不接受；遇到时请改成等音升号（例如 `b2` 写作 `#1`）。

## 五套键盘映射

所有乐器共用同一套简谱语义：1–7、高低音、八度、延音。具体键位在舞台下方的提示条里实时显示。

### 钢琴（两种键位布局，可在键盘上方切换）

钢琴提供两种布局，选择会记住，下次打开自动沿用。**两种布局的声音本身完全一样，只是键位排布不同。**

**布局一 · 钢琴**（贴近真实钢琴，上排为黑键）

| 按键 | 功能 |
| --- | --- |
| `A S D F G H J` | 中音区 1–7 |
| `W E T Y U` | 中音区 #1 #2 #4 #5 #6（黑键/升音） |
| `Z X C V B N M` | 低音区 1–7（比中音低一个八度） |
| `Shift + 主键` | 再升高八度 |
| `Ctrl + 主键` | 再降低八度 |

**布局二 · 简谱音高**（三排严格按高/中/低音分层，贴合简谱上下加点）

| 按键 | 功能 |
| --- | --- |
| `Q W E R T Y U` | 高音区 1'–7'（数字上方带点，比中音高一个八度） |
| `A S D F G H J` | 中音区 1–7 |
| `Z X C V B N M` | 低音区 1.–7.（数字下方带点，比中音低一个八度） |
| `Ctrl + 主键` | 升半音（#） |
| `Shift + 主键` | 再升高八度 |

> 三排共 21 个音、覆盖三个八度。两种布局都支持长按持续发声，长按期间切换 Shift/Ctrl 会即时变音。

### 吉他

标准调弦：1 弦高音 E4，2 弦 B3，3 弦 G3，4 弦 D3，5 弦 A2，6 弦低音 E2。

| 按键 | 功能 |
| --- | --- |
| `1 2 3 4 5 6` | 六根空弦（1 弦到 6 弦） |
| `Q W E R T Y` | 1 弦 1–6 品 |
| `A S D F G H` | 2 弦 1–6 品 |
| `Z X C V B N` | 3 弦 1–6 品 |
| `Shift + QWERTY` | 4 弦 1–6 品 |
| `Shift + ASDFGH` | 5 弦 1–6 品 |
| `Shift + ZXCVBN` | 6 弦 1–6 品 |
| 长按 | 持续发声；延音期间换品会结束当前音并触发新音 |

### 小提琴

| 按键 | 功能 |
| --- | --- |
| `A–J` | 低把位基础音 1–7 |
| `Shift + 主键` | 高把位（高八度） |
| `Ctrl + 主键` | 半音 |
| 长按 | 持续发声；按住期间切换 Shift 会立即切换当前延音的音区 |

### 萨克斯 / 笛子

| 按键 | 功能 |
| --- | --- |
| `A–J` | 基础指法 1–7 |
| `Shift + 主键` | 超吹高音（高八度） |
| `Ctrl + 主键` | 半音 |
| 长按 | 持续吹气延音；按住期间切换 Shift 会切到超吹延音 |

修饰键优先级：超吹 > 八度/把位 > 半音。多个修饰键同时按下时按此顺序处理。

### 基准八度与浏览器快捷键

左侧「键盘基准八度」可以整体移动音区，适合在 Ctrl+W 等组合被浏览器拦截时继续演奏。全局快捷键：

- `Space`：播放 / 暂停（焦点不在输入框或按钮上时）。
- `Esc`：停止所有正在发声的键与播放。
- `Ctrl/Cmd + Enter`：在简谱输入框中解析并载入。

## 播放与编配

- **调速**：速度滑杆实时生效；播放中修改会在当前位置重新排程。
- **节拍器**：AudioContext 驱动的短促提示音；Canvas 同步显示当前小节节拍点。
- **整曲循环**：从头到尾循环。
- **A–B 循环**：标记 A、B 后只循环这一段；进度条上有区间标记。
- **进度拖拽**：拖动时暂停，松手后从新位置继续。
- **智能编配**：按乐谱跨度、密度、速度、五声性判定流派，给出主奏/伴奏/混响/速度建议；所有建议都可以在左侧手动覆盖。

搜谱不会爬取网页：输入曲名后在新标签页打开搜索引擎，你手动复制简谱文本，再粘贴回输入框解析。

## 音频与光效实现

### 音频

- 首次用户手势唤醒 `AudioContext`，避免浏览器自动播放限制。
- 音色按乐器懒加载；音色缺失、脚本失败或解码超时时，自动降级到内置合成音色并给出提示。
- 每种乐器独立配置 `minMidi / maxMidi`。演奏时如果超出音域，会优先通过移动八度适配；无法适配的音符静音，不中断播放。
- 采样音色与合成音色共用统一 ADSR、乐器音量、总音量与混响总线。
- 混响通过 ConvolverNode + 程序生成的脉冲响应实现，长/短两套预设。
- 播放调度全部使用 `AudioContext.currentTime`，用短间隔调度器提前把音符写入音频时间线。

### 视觉

- Canvas 2D 固定 `globalCompositeOperation = 'screen'` 做滤色叠加。
- 光效全部由径向/线性渐变组成，没有硬边贴图。
- 粒子使用预分配对象池复用，避免高频演奏时持续分配对象。
- 渲染与播放共享音频时钟；音符事件的时间点来自 `AudioContext.currentTime`。
- 五种乐器有独立光效：钢琴垂直光柱、吉他的水平擦弦拖尾、小提琴的指板流光、萨克斯的锥形气流、笛子的指孔双侧迸发。
- 主题面板支持粒子亮度、密度、主色；HEX / RGB 双向转换与一键复制，设置保存在 `localStorage`。

## 音色替换

1. 把 WebAudioFont 音色 JS 文件放进 `vendor/soundfonts/`。
2. 编辑 `src/instruments.js` 中对应乐器的 `soundfont.file` 与 `soundfont.variable`。
3. 变量名必须与音色文件里 `var _tone_xxxx_... = {...}` 的全局变量名一致。
4. 如果要换整套采样库，也可以同时调整 `src/audioEngine.js` 中的 `vendor/WebAudioFontPlayer.js` 路径。

本地音色文件来源：

- 播放器：<https://github.com/surikov/webaudiofont>
- 音色数据：<https://github.com/surikov/webaudiofontdata>

如果文件缺失或路径错误，演奏仍会继续，使用内置合成音色；控制面板会出现「重试采样音色」按钮。

## GitHub Pages 部署

1. 把整个目录提交到 GitHub 仓库（保持 `index.html`、`styles/`、`src/`、`vendor/` 的相对路径不变）。
2. 仓库 Settings → Pages → Build and deployment，选择 `Deploy from a branch`。
3. 分支选 `main`，目录选 `/ (root)`，保存。
4. 等待 Pages 构建完成，访问 `https://<用户名>.github.io/<仓库名>/`。
5. 项目已含 `404.html`，GitHub Pages 会用它处理未知路径。404 页会向上探测仓库根目录，因此部署在 `/<repo>/` 子路径、且缺失路径较深时，样式与返回链接也能正确加载。
6. `.nojekyll` 可避免 GitHub Pages 对静态文件做 Jekyll 处理。

如果部署到子路径，所有资源都使用相对路径，不需要修改配置。

## AI 辅助转换（可选）

演奏台「简谱」区域有一个「复制格式给AI」按钮。它会把下面这段格式说明复制到剪贴板，你可以发给任意 AI，让 AI 把歌曲或其它格式的简谱转换成本项目支持的文本，然后粘贴回输入框解析。

```text
请按照下面这套简谱规范输出乐谱文本，只输出乐谱，不要额外解释、不要markdown、不要五线谱、不要图片、不要注释。
格式规则：
1. 第一行写明调号、拍号、速度，格式：1=C 4/4 ♩=80；如果没有指定，默认使用 1=C 4/4 ♩=80
2. 基础音符：1 2 3 4 5 6 7
3. 低音标记：数字后面加英文句号，例如 1. 代表低音1
4. 高音标记：数字后面加英文单引号，例如 1' 代表高音1
5. 升半音标记：# + 音符，例如 #1 #2 #4
6. 时值规则：默认四分音符；1- 为二分音符；1_ 为八分音符
7. 延音标记：波浪号 ~，例如 5~
8. 小节之间用竖线 | 分隔，音符之间用空格隔开
9. 不支持装饰音、滑音、反复记号、房子记号、强弱记号，遇到这类记号请简化为普通音符与时值
示例：1=C 4/4 ♩=80
5 3 5 | 6 5 3 | 2 3 5 1' | 1' - |
```

提示：明确要求 AI **只输出乐谱**，不要解释、不要 Markdown；否则粘贴回来可能无法解析。

## 隐私与数据

- 没有后端，不上传简谱，不读取搜索页面内容。
- 搜谱只是用 `window.open` 打开搜索引擎，后续复制粘贴由你手动完成。
- 主题设置写入浏览器 `localStorage`；清除站点数据即可恢复默认。
- 首次点击/按键会创建 AudioContext；页面本身不采集音频输入。

---

## 已知限制

- 没有触屏虚拟键盘；移动端只做浏览、搜谱、解析和播放。
- 简谱解析是约定格式解析，不做图片 OCR，不支持多声部/和弦。
- 采样音色来自第三方 SoundFont，音域与表现力受音色文件本身限制。
- 浏览器可能拦截部分 Ctrl 组合键；使用「键盘基准八度」或界面控件绕过。
- 播放中的采样音色使用外层 ADSR，音色的原始 AHDSR 被关闭，以保持统一包络。
- 低音长音受采样长度限制，极长的持音可能提前结束。
