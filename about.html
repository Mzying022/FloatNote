About FloatNote

把简谱，放进一束
会呼吸的光里。

FloatNote 是一个个人自娱向的开源实验：用一张网页，把文本简谱变成五种乐器的声音， 再用 Canvas 2D 把每一个音画成一束柔光。没有后端，没有构建，没有账号，也没有需要上传的乐谱。

01 · Position

它是什么，不是什么

FloatNote 是一个纯静态音乐交互网页。官方只要求你把它放到任意静态 HTTP 服务上， 就能浏览、搜谱、解析简谱、播放声音。它不提供图片 OCR，不做爬虫，也不托管你的乐谱。

它适合个人练习、听旋律、试验不同乐器的音色和光效。它不是专业制谱软件，也不试图替代完整 DAW。 所有简谱文本只留在当前浏览器里，搜索由你自己在新标签页完成。

硬性约束

  • 原生 HTML5 + CSS3 + ES Modules，无前端框架、无打包工具、无后端服务。
  • Canvas 2D 渲染；WebAudio API + WebAudioFont 本地采样音色。
  • jQuery CDN 只用于主题调色面板，演奏、解析、渲染核心完全不依赖 jQuery。
  • 桌面端完整 QWERTY 演奏；移动端保留浏览、搜谱、播放，不提供触屏虚拟键盘。
02 · Light

光为什么看起来在呼吸

舞台上没有一张位图素材。所有光都用 Canvas 2D 径向渐变与线性渐变绘制， 并固定使用 globalCompositeOperation = 'screen' 做滤色叠加。光与光相遇时只会变亮， 不会出现生硬的边界。

粒子不是每帧新建的对象，而是从预分配的对象池里借出、归还、复用。 这样长音、快速跑句和反复循环都不会持续制造垃圾对象，画面也不容易在演奏高潮时掉帧。

五种光效

钢琴的垂直光柱随音高变细变亮；吉他的擦弦拖尾随低音拉长；小提琴的指板流光在高把位更密； 萨克斯的锥形气流随时值衰减；笛子的指孔向两侧迸发短促光点。乐器切换时，光的形态也一起切换。

03 · Sync

声画同步：让眼睛相信耳朵

播放调度统一使用 AudioContext.currentTime：每个音符、每个节拍器点击都被换算成精确的 音频时间点，再提前排入 WebAudio 时间线。Canvas 的渲染循环也读取同一个音频时钟， 粒子的产生、乐器的光柱、节拍光标与小节进度因此共享一套时间，而不是各跑各的 performance.now()。

A

提前 0.42 秒排程

用短间隔调度器把即将到来的音符写入音频时间线，避免主线程抖动造成的节奏毛刺。

B

段循环与 A–B

整曲循环与 A–B 循环通过循环段调度实现，声音与画面在边界处共同回卷。

C

逐音包络

采样音色与内置合成兜底共用统一的 ADSR、音量与长/短混响总线。

五束光，五种性格

音色、光效与演奏手感是一起设计的

钢琴

按键触发垂直光柱，粒子从键面向上扩散。音越高，光柱越细、越亮。

88 keys · long reverb

吉他

水平琴弦滑动光效，品格按压处生成横向擦弦拖尾。低音拖尾更长、更柔和。

6 strings · short reverb

小提琴

指板纵向流光滑动。高把位的粒子密度更高，长音会持续呼吸。

4 strings · long reverb

萨克斯

吹口向前的锥形气流，随音符时值逐渐衰减。按键孔会跟着音高亮起。

alto sax · short reverb

笛子

指孔双侧短促迸发光点。高音区明度更高、迸发速度更快，气息感更轻。

C4 – C7 · short reverb

乐器搭配科普

智能编配推荐的依据

编配不是玄学，至少在这个项目里不是。规则会先读乐谱的音域跨度、节奏密度、速度与五声性， 给出古典、民乐、通俗三种流派倾向；再按每种乐器的音域、音色家族与流派契合度排序主奏。

键盘 × 弦乐 钢琴颗粒清晰、和声完整；小提琴线条连贯。一个负责骨架，一个负责呼吸，是最稳的主奏组合之一。
气鸣 × 拨弦 笛子与吉他的瞬态差异很大：一个靠气息，一个靠拨弦。音色区分度高，适合民乐或轻快的通俗旋律。
簧管 × 键盘 萨克斯的沙哑中频与钢琴的明亮高频互补。萨克斯做主奏时，键盘适合铺和声或提供节奏骨架。
同族叠加要克制 两支气鸣乐器或两支弓弦乐器同时出现时，频段容易挤在一起；此时更需要用音区、音量和混响拉开距离。

混响不是越多越好

钢琴与小提琴默认长混响，让尾音在空间里自然扩散；吉他、萨克斯、笛子默认短混响， 保持颗粒与节奏轮廓。你可以在控制面板里关闭混响、调整湿度，或直接应用编配建议。

音量与动态

总音量、乐器音量与混响湿度是三条独立的线。总音量控制整体出口；乐器音量控制当前音色的存在感； 混响湿度只控制送进混响空间的比例。所有音符共享同一套 ADSR 包络参数， 但音符力度与音高会改变光效的大小与亮度。

越界音符

每种乐器有独立音域。超出音域的音符会自动移八度适配，并在乐谱预览中标记； 如果移八度后仍无法落进音域，该音符保持静音，不会中断整首播放。

怎么演奏

标准 QWERTY · 桌面端完整演奏

五套键位共用同一套简谱语义（1–7、高低音、八度、延音），但每个乐器的物理键位独立分配。 同一个按键在不同乐器上可以代表不同简谱音级；具体映射始终显示在舞台下方的键位提示条里。

乐器主键位修饰键 / 音域
钢琴A S D F G H J = 1–7W E T Y U = #1 #2 #4 #5 #6；Shift 高八度，Ctrl 低八度
吉他1–6 = 六根空弦；QWERTY / ASDFGH / ZXCVBN = 前三弦品格Shift + 字母 = 4–6 弦品格；长按延音，换品重触发
小提琴A–J = 低把位 1–7Shift = 高把位；Ctrl = 半音
萨克斯A–J = 基础指法 1–7Shift = 超吹；Ctrl = 半音
笛子A–J = 基础指法 1–7Shift = 超吹；Ctrl = 半音

长按与修饰键

按住任意映射键就会持续发声；超过 380 毫秒后，舞台会把它标记为“延音”。 在按住期间切换 Shift / Ctrl，当前音会立即切换八度、把位或半音，而不会中断。 多个修饰键同时按下时，优先级是：超吹 > 八度 / 把位 > 半音。

全局快捷键

  • Space：播放 / 暂停（焦点不在输入框或按钮上时）。
  • Esc：停止所有正在发声的键与播放。
  • Ctrl / Cmd + Enter：在简谱输入框中解析并载入。

浏览器冲突

部分组合（例如 Ctrl + W）会被浏览器优先处理，网页无法完全拦截。遇到这类情况， 请使用控制面板里的“键盘基准八度”按钮整体移八度，或改用上方的界面控件。

移动端

移动端不提供触屏虚拟键盘。你仍然可以浏览界面、搜索简谱、粘贴解析、播放、调速、循环与标记 A–B； 键盘演奏提示会自动隐藏。

文本简谱规范

能被这个解析器读懂的写法

开头可以写一行声明；不写时默认 C 调、4/4 拍、80 BPM。

1=C 4/4 ♩=80 5 3 5 | 6 5 3 | 2 3 5 1' | 1' - |
写法含义
1=C / 1=G / 1=F调号；支持常见的升号、降号调名
4/4 / 3/4 / 2/4拍号；也接受 6/8 等分母为 2、4、8、16 的拍号
♩=80 / BPM=80速度，范围 20–300 BPM
1 2 3 4 5 6 7基础音级，默认四分音符
1. / 1'低八度 / 高八度，可叠加
#1升半音
1_八分音符；多个下划线继续减半
1-二分音符；单独的 - 延长前一拍
1~连音线；与同音高的下一个音合并时值
|小节线
0休止符（兼容扩展，不是原始规范的一部分）

解析器会做什么

先清洗文本、识别首行声明，再按小节线和小节内的空格拆分音符，逐个读取音级、八度、半音、时值、连音线与小节编号， 最后输出标准化的音符数组。解析错误会带行号、列号与原因；小节拍数与拍号不一致时会给出提示，但不会阻止播放。

暂不支持

  • 装饰音、滑音、强弱记号、反复记号、房子记号。
  • 图片、PDF、图片 OCR、五线谱。
  • 降号写法（遇到时请改成等音升号，例如 b2 写成 #1）。
  • 多声部、和弦同时发声、歌词对齐。

AI 辅助转换

演奏台右侧有一个“复制格式给AI”按钮。它复制一份格式说明，你可以发给任意 AI， 让 AI 把歌曲或其它格式的简谱转换成本软件支持的纯文本乐谱，再粘贴回输入框解析。 建议明确告诉 AI：只输出乐谱，不要解释、不要 Markdown。
